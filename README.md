# NEXVION - E-Commerce Application

## Project Overview

NEXVION is an e-commerce web application used as the application source for the DevOps and Cloud-Native Delivery Platform project.

The application source is maintained in GitHub and will be integrated with Docker, Jenkins, Terraform, Ansible, Kubernetes, monitoring, logging, and DevSecOps practices.

## Current Application

The application consists of:

- HTML
- CSS
- JavaScript

## DevOps Project

The DevOps implementation will include:

- Git & GitHub
- Bash Automation
- Docker
- Docker Compose
- Jenkins CI/CD
- DevSecOps
- Terraform
- Ansible
- Kubernetes
- Helm
- Prometheus
- Grafana
- ELK
- AWS
